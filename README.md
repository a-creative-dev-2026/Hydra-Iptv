# 🐍 Hydra IPTV v4.0

![Version](https://img.shields.io/badge/version-4.0.0-blue)
![Python](https://img.shields.io/badge/python-3.11-green)
![Framework](https://img.shields.io/badge/framework-FastAPI-red)

**Hydra IPTV** هو خادم بروكسي ذكي ومتطور مصمم لجلب قنوات IPTV من مصادر عالمية متعددة بكفاءة عالية وبدون تقطيع. تم إعادة بناء هذا الإصدار بالكامل باستخدام **FastAPI** لضمان السرعة القصوى والأداء الاحترافي.

## 🚀 المميزات الجديدة في v4.0

- **أداء فائق السرعة**: تم الانتقال إلى FastAPI و Uvicorn لدعم العمليات غير المتزامنة (Asynchronous).
- **محرك بحث ذكي**: يستخدم خوارزميات البحث الضبابي (Fuzzy Search) لإيجاد القنوات بدقة عالية.
- **بروكسي متطور**: يدعم البث المباشر عبر البروكسي لتجاوز مشاكل CORS وتحسين استقرار البث.
- **لوحة تحكم احترافية**: واجهة مستخدم عصرية لمراقبة حالة السيرفر والبحث عن القنوات وتجربتها.
- **نظام كاش ذكي**: تخزين مؤقت للنتائج لتقليل زمن الاستجابة وتوفير الموارد.
- **دعم عالمي**: يغطي أكثر من 190 دولة و30 تصنيفاً مختلفاً.

## 🏗️ هيكل المشروع

```text
Hydra-IPTV/
├── api/            # مسارات الـ API
├── core/           # المنطق البرمجي (البحث، البروكسي)
├── db/             # قواعد البيانات والكاش
├── models/         # نماذج البيانات (Pydantic)
├── static/         # واجهة المستخدم (HTML/JS)
├── main.py         # نقطة انطلاق التطبيق
└── requirements.txt # المكتبات المطلوبة
```

## 🛠️ البدء السريع

### التشغيل محلياً

1. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```

2. تشغيل السيرفر:
   ```bash
   python main.py
   ```

3. افتح المتصفح على: `http://localhost:5000`

### النشر على Render / Heroku

المشروع جاهز للنشر مباشرة. استخدم ملف `Dockerfile` أو `render.yaml` المرفق.

## 📡 نقاط النهاية (API Endpoints)

| المسار | الوصف |
| :--- | :--- |
| `GET /` | واجهة المستخدم (Dashboard) |
| `GET /search/{query}` | البحث عن قناة معينة |
| `GET /channel/{name}` | تشغيل قناة مباشرة عبر البروكسي |
| `GET /countries` | قائمة الدول المدعومة |
| `GET /categories` | قائمة التصنيفات المدعومة |
| `GET /stats` | إحصائيات السيرفر والكاش |
